# Производственный комплект — Cambridge 640A V1

[English](README.en.md) · [Скачать ZIP для производства](Cambridge_640A_PowerAmp_production.zip) · [Контрольные суммы](SHA256SUMS.txt)

Этот архив Gerber X2 и сверловки Excellon относится к предыдущей ревизии платы. Его исходный PCB экспортирован в KiCad 10. Исходная плата при экспорте не изменяется; её SHA-256 записан в [манифесте](manifest.json).

| Параметр заказа | Значение |
|---|---|
| Размер по контуру | 198,9259 × 129,9597 мм, форма по Edge.Cuts |
| Материал / толщина | FR4 / 1,6 мм |
| Порядок меди сверху вниз | F.Cu → In1.Cu → In2.Cu → B.Cu |
| Толщина меди по проекту | 70 / 35 / 35 / 70 мкм; согласовать готовую толщину с изготовителем |
| Маска / шелкография | С двух сторон |
| Металлизированные отверстия | 648, отдельный PTH-файл |
| Неметаллизированные отверстия | 8, отдельный NPTH-файл |
| Отдельные переходные отверстия | 0 |
| Координаты | Абсолютные, мм, общие для Gerber и Excellon; без зеркалирования |

## Состав

- `gerbers/`: четыре слоя меди, две маски, две шелкографии, контур и Gerber Job.
- `drill/`: PTH и NPTH Excellon, две карты сверловки PDF и отчёт по диаметрам.
- `validation/`: DRC с проверкой соответствия схеме и отчёт с исключениями.
- [Требования к изготовлению](FABRICATION_NOTES.txt), [манифест состава](manifest.json) и [SHA256](SHA256SUMS.txt).

Для заказа загрузить весь ZIP. Медь и сверловку не зеркалировать. Отдельные файлы доступны в тех же каталогах репозитория.

## Проверка и повторный экспорт

Нативная проверка KiCad 10: 0 активных нарушений DRC, 0 несоединений, 0 расхождений со схемой. Принятые исключения и настройки правил сохранены в отчёте; это не новая настройка ограничений платы.

Команда из корня репозитория: `python scripts/build_production.py`. Требуется установленный KiCad 10; путь к CLI можно задать переменной `KICAD_CLI`.
