# Уточнения к документам по сборке

[Полный список документов по сборке](../../README.md#документы-по-сборке) · [Текущий BOM](../../BOM.md) · [Актуальный план компонентов](../v2/layer-plans/components.pdf)

Восстановленные PDF — рабочие материалы для ранее изготовленной v2, сохранённые в исходном виде. Подробная инструкция от 05.11.2026 содержит 13 шагов; первоначальный порядок сборки — 12 этапов. Карты резисторов служат приложением к подробной инструкции. Расположение и посадки текущей ревизии проверять по актуальному плану и PCB.

## Уточнения, заменяющие указания ранних PDF

- **U8 — 7805.** Эксперимент с TRACO TSR 1-2450 отменён, C81 удалён из текущего проекта. Указания старых PDF об установке TSR/C81 не применять.
- **Изоляция стабилизаторов.** Для U8/U9/U10 предусмотрены изоляционные комплекты по текущему BOM. На изготовленной плате радиатор соединён с землёй крепежом: U8 также требует изолирующей прокладки и изолированного крепежа; прежнее указание «U8 без изолятора» отменено.
- **CN21 текущей ревизии — JST VH**, в ранних PDF и на изготовленной плате — XH. Посадка и ориентация изменились. Номер контакта и проводку определять по [актуальной таблице подключения](../v2/WIRING.md), а не по положению разъёма на старом рисунке.
- **R88 — 11 кОм, 0,25 Вт**; в приложении от 05.11 указано 0,125 Вт. **R44/R50 — 4,7 Ом, 3 Вт** по текущему BOM; в ранней карте встречается 2 Вт. Остальные номиналы, мощности и исполнения также сверять с текущим BOM.
- **C13/C47 — неполярные NP/BP.** Текущие посадки C13/C47 и C22/C42 — Ø8 мм, шаг 3,5 мм; C70/C71/C74/C75 — Ø10 мм, шаг 5 мм. Старые PDF отражают прежнюю геометрию; она не меняется на уже изготовленной плате при обновлении исходников.
- **C16/C44 — DNP.** Номера подобранных транзисторов в инструкции относятся только к измеренной партии владельца, а отметки переноса деталей не подтверждают завершение монтажа.

После монтажа использовать [инструкцию первого включения и настройки](../v2/FIRST_POWER_UP_V2.md) ([PDF](../v2/FIRST_POWER_UP_V2.pdf)).
