# Проверка переноса CN21 на JST VH

Дата: 2026-11-15. Исходники: `640A_PowerAmp.kicad_pcb` и `power_supply.kicad_sch`.

* CN21: `JST_VH_B3P-VH_1x03_P3.96mm_Vertical`, центр X244,5/Y147 мм, поворот 180°.
* Контакты 1/2/3 сохранены на цепях `Net-(CN21-Pin_1)` / `AUX0V` / `Net-(CN21-Pin_3)`; координаты новых площадок X244,5 / X240,54 / X236,58 мм при Y147 мм.
* CN21 перенесён из прежнего места, где его корпус перекрывал зоны D14–D16 и подходил примерно на 0,4 мм к правому краю платы. На новом месте зазор от контура корпуса до правого края около 2 мм. Другие компоненты перемещать не понадобилось.
* Дорожки трёх цепей и цепи `digital` перепроложены. Для связи слоёв добавлены три переходных отверстия; позиции X244,314/Y166,211 и X244,314/Y168,711 соединяют новые дорожки со старыми, X233/Y143 соединяет участки `digital`.
* Шелкография R86 сдвинута ниже резистора после замечания DRC о пересечении с обозначением корпуса CN21.
* KiCad CLI 10.0.7: DRC с перезаливкой полигонов и сохранением платы — **0 нарушений, 0 неразведённых соединений**. Повторный DRC сохранённого файла без перезаливки также — **0/0**.

Электрическую проверку собранной платы и выпуск Gerber эта проверка не заменяет.
