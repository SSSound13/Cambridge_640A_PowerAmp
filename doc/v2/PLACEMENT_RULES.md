# Правила перерасстановки парных узлов v2

Согласованы с пользователем 13.11.2026. Для шести увеличиваемых конденсаторов
и необходимых соседей требуется симметричное **итоговое размещение**, а не
одинаковое приращение к уже различающимся исходным координатам.

## Геометрия

1. Сопоставлять детали по электрической схеме, а не по близости на плате.
2. Для рассматриваемого верхнего участка использовать одинаковую ориентацию
   двух каналов с параллельным переносом, без зеркального разворота выводов.
   Начала локальных координат — вывод 1 U2 и вывод 1 U4:
   (73,5809; 61,0680) и (172,5367; 61,0680) мм. Перенос X = 98,9558 мм.
3. Основная локальная сетка 0,5 мм, уточняющая 0,25 мм. Дробные мировые
   координаты механических опор сохраняются; привязка задаётся относительно них.
4. Расстояния между отверстиями определяются корпусом. Не округлять 2,5;
   3,5; 5; 7,62; 10,16 мм ради попадания каждого отверстия на одну сетку.
5. У парных деталей должны совпадать относительные координаты и ориентация.
   Если одна сторона не помещается, пересматривать обе стороны. Исключения
   не вводить молча. Для одинаковых элементов унифицировать корпус, footprint,
   шаг, сверловку и размеры площадок до размещения. Если исходные требования
   к мощности или напряжению различаются, сначала выбрать общее исполнение,
   удовлетворяющее более строгому требованию; не снижать номинальную мощность
   или допустимое напряжение ради одинакового корпуса.
6. Резисторы в группе выравнивать по выбранной колонке отверстий. При одинаковом
   шаге совпадают обе колонки; при разных шагах сохранять одну общую колонку.
   Интервалы рядов внутри группы одинаковы, по размеру самой крупной детали.
7. Для C13/C47 приняты Ø8/P3,5, для C70/C71/C74/C75 — Ø10/P5.
   Неполярность C13/C47, номера выводов и электрические номиналы сохраняются.
8. Ориентир между реальными корпусами — не менее 1 мм с учётом допусков.
   Для горячих деталей, регулировки и крепежа нужен отдельный больший запас.
   Проверка courtyard — необходимая проверка, но не замена чертежам деталей.

## Электрика и границы изменений

- Механические отверстия, контур платы, SAP15 и разъёмы фиксированы.
- Можно двигать целые парные узлы и необходимых соседей. Нельзя расширять контур
  без проверки корпуса усилителя и отдельного согласования.
- Сохранять короткие цепи обратной связи и развязки, ширины силовых дорожек,
  структуру земель и электрическую связность. Эстетика не оправдывает ухудшения цепи.
- Подписи размещать после компоновки и разводки: единый размер, читаемость,
  однозначная полярность. Не уменьшать подписи для сокрытия тесноты.
- После каждого законченного участка проверять симметрию численно, сверять
  схему и плату, перезаливать зоны и выполнять DRC. Новые нарушения не скрывать
  дополнительными исключениями. Перед выпуском повторить ERC.
- Черновик размещения без законченной разводки не является производственной платой.
  Новые Gerber выпускаются только после завершения проверок.

## Правила трассировки парных узлов

1. Для одинаково расставленных пар строить один образец дорожек и переносить его на соответствующие сети другого канала. Проверять препятствия обоих каналов до принятия образца. Независимая трассировка двух копий внутри общего узла недопустима.
2. Парными должны быть не только осевые линии: сохранять одинаковые слои, ширины, переходы, диаметры площадок и сверловку. Любую правку общего рисунка выполнять в обеих копиях.
3. Новые сигнальные дорожки — 0,5 мм; GND — 0,8 мм; +45 В, −45 В, RO/LO и RE1/RE2/LE1/LE2 — 2 мм. Существующие магистрали PGND 2/3 мм не заужать. Остальные сохранённые цепи подчиняются своим классам проекта.
4. Для новых силовых переходов применять Ø1,2/сверло 0,6 мм, для сигнальных — Ø0,6/0,3 мм. Использовать штатный сквозной вывод для смены слоя, если это позволяет избежать лишнего сверления. Не сверлить второй раз поверх вывода.
5. Не уменьшать назначенную ширину ради прохождения тесного места: менять путь, сохраняя зазор. Для общего рисунка менять оба канала.
6. Отличающиеся подключения допустимы на границе с различно расположенными неподвижными деталями. Вести отдельную таблицу их концов, сетей, ширин, длин и переходов. Они не должны заменять соединения внутри общего рисунка.
7. Приёмка: численное сравнение всего общего рисунка в сохранённой PCB, проверка полноты соединения соответствующих выводов, фактических ширин, сетей и координат; затем заливка зон, DRC со сверкой схемы и ERC. Исключения DRC для сокрытия новых нарушений не добавлять.

## Геометрия дорожек после проверки трассировщика

8. Результат сеточного поиска не считать готовой трассировкой. Убирать повторяющиеся короткие ступени; предпочитать прямые участки и небольшое число поворотов 45°. Сохранять реальные координаты выводов и точки ответвлений.
9. При равной длине выбирать путь с меньшим числом поворотов. Длину оценивать по электрической цепи целиком, особенно для обратной связи, компенсации и развязки питания.
10. Длинные обходы проверять вручную с учётом соседних цепей. Перестройка соседнего сигнального подключения может освободить короткий путь для питания; не заужать питание ради обхода.
11. Любое упрощение проверять по меди обоих каналов, включая отверстия NPTH и ответвления. Отдельно проверять геометрию, связность и DRC; отсутствие ошибок DRC само по себе не подтверждает качество разводки.
