# Проверка разводки всех четырёх слоёв

17 ноября 2026 года. Эта редакция заменяет предыдущий обзор с 1401 сегментом. Проверены дорожки всей платы: соединения, ширины, углы, дубли, заливки и соответствие схеме. Расстановка компонентов сохранена.

## Ориентир по числу сегментов

За исходную изготовленную версию принят PCB из коммита [8b50969](https://github.com/SSSound13/Cambridge_640A_PowerAmp/commit/8b50969): запись CHANGELOG от 3 октября «перед заказом» и архив 640A_PowerAmp_v2_fab_2026-10-03.zip находятся в той же версии. PCB взят из коммита, а не извлечён из Gerber. Более поздний производственный экспорт с 1888 сегментами для сравнения не использовался.

| Показатель | Исходная версия | Текущая версия |
| --- | ---: | ---: |
| Сегменты дорожек | 1368 | 1391 |
| Переходные отверстия | 21 | 0 |
| Рост числа сегментов | — | 1,68% |
| Допустимый максимум при +3% | — | 1409 |

Считаются объекты segment в PCB, одинаковым способом для обеих версий. Переходы и вершины полигонов в это число не входят. Лимит соблюдён: осталось 18 сегментов запаса. Число сегментов дополняет проверки соединений и тока, но само по себе не подтверждает качество трассировки.

## Исправленные соединения и пути

- На B.Cu у PGND около (191,7; 79,5) мм было соединение только краями закруглений: перекрытие около 0,020 мм. Теперь осевые линии стыкуются, медь имеет полную ширину. Аналогичные стыки проверены по всей плате.
- Проверка исходного варианта выявила 121 конец дорожки вне собственной площадки, заливки или осевой линии другой дорожки. Это кандидаты на ненадёжное соединение, а не 121 электрический обрыв. После исправлений таких концов нет. Точные дубли удалены; стык у Q33 доведён внутрь площадки.
- На In1.Cu участок +45 В у C26 ранее имел только одну подключённую площадку. Теперь он соединён широкой заливкой с D17.1. Вторая рабочая ветвь соединяет C25.1 и D20.1. Эти две области связаны с общей сетью питания через внешнюю медь. Удалены одноплощадочные выступы возле SAP; питание SAP идёт по внешним дорожкам 2 мм.
- На F.Cu убран возвратный обход у D2. При общей оптимизации переносились точки ответвлений на магистралях, чтобы уменьшать обходы без острых примыканий и касаний закруглёнными концами. Сохраняется 21 пара целых цепей с одинаковой геометрией после согласованного сдвига.
- На In2.Cu сохранены широкие левое и правое соединения PGND с центральной областью. Единство этих областей подтверждено по фактически залитой меди. Центральный выходной возврат на F.Cu использует ветви 2 мм и общий участок 3,5 мм.

## Итоговые проверки

| Показатель | Перед этой правкой | Сейчас |
| --- | ---: | ---: |
| Сегменты | 1401 | 1391 |
| Суммарная длина дорожек | 7745,00 мм | 7801,54 мм |
| Концы вне площадок / зон / осевых соединений | 121 | 0 |

Небольшое увеличение длины связано с восстановлением полноценных контактов и переносом управляющего пути, разрезавшего полигон питания. Оно не скрыто сокращением числа сегментов.

По слоям: F.Cu — 423, B.Cu — 611, In1.Cu — 236, In2.Cu — 121 сегмент. Ширины: 0,5 / 0,8 / 1 / 2 / 3,5 мм. Точных дублей нет. Проверка осевых линий вне площадок: 0 острых примыканий и 0 отрезков вне направлений 0°/45°/90°. Остаются четыре коротких локальных соединения менее 0,5 мм, перечисленные в geometry-final.json. Проверка осей не означает отсутствие любых острых деталей границ полигонов или посадочных мест.

296 блоков компонентов и 656 площадок сохранены точно, включая Q20 и SAP. 21 пара целых цепей совпадает после сдвига: по 121 сегменту с каждой стороны. Все десять отверстий проверены; у H9 дорожка проходит в 1,079 мм от края отверстия. У H7/H8 зазоры от края медной площадки до дорожки — 1,034 / 1,209 мм.

KiCad 10.0.7: 0 нарушений по меди, 0 висящих концов, 0 несоединений, 0 расхождений со схемой. Активные замечания: 199 silk_overlap, 44 silk_over_copper и одно пересечение монтажных контуров D2/R107. Дополнительный отчёт с включёнными прежними исключениями содержит ещё 23 пересечения монтажных контуров. Исключения и уровни серьёзности не изменялись; полный DRC не объявляется чистым.

Выходные цепи — 2 мм на внешней меди 70 мкм, основные трансформаторные — 3,5 мм снаружи. Расчёты распределения выходного тока и сопротивления центрального PGND повторены. Для PGND на внутренней меди 35 мкм получено 0,670 / 0,657 мОм на сетках 0,25 / 0,125 мм; при условных 10 А — 0,066–0,067 Вт. Это модель сопротивления, не тепловое испытание или измерение зарядных импульсов. [Проверка токов и ширин](ROUTING_CURRENT_REVIEW.md).
