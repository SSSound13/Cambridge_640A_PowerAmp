# Конденсаторы: план типовых посадочных мест для v3

Предварительный ориентир для переразводки **основной платы**. Список взят из
`BOM.md` и `640A_PowerAmp.kicad_pcb` v2; `Ø` — максимальный диаметр корпуса,
`L×W` — проекция прямоугольного корпуса, `P` — шаг выводов в миллиметрах.
Электрические номиналы здесь сохранены из BOM; напряжение, полярность и тип
проверяются по схеме перед заменой детали. В таблице указана посадка, которую
нужно обеспечить, а не гарантированный размер всех товаров данного номинала.
Выбирать конкретные детали по чертежам производителя до завершения v3.

## Обязательная проверка компоновки

- По центрам v2 C22 Ø8 пересекается с C21 Ø18 на 1,19 мм и C23 Ø18 на 0,95 мм;
  C42 Ø8 пересекается с C41 Ø8 на 0,94 мм. Подъём на 3 мм эти конфликты не снимает.
- C13/C47 Ø7 пересекаются с **проектными контурами** C46/C48 на 1,10/0,91 мм.
  Фактические корпуса установленных TDK пока не измерены. Для v3 подбирать и
  размещать эти пары совместно; проверить также диоды D4/D10.
- C70/C71/C74/C75 Ø8,1 мм оставляют зазоры порядка десятых долей миллиметра
  либо пересекаются с контурами соседней керамики и R53. Переставить детали так,
  чтобы реальные корпуса и их допуски имели монтажный запас; оценить высоту.
- C60/C61 практически соприкасаются уже при Ø5. Для нового варианта раздвинуть.
- Проверить **все** пары по фактическим диаметрам и высотам выбранных артикулов,
  разъёмы, радиатор, крышку и 3D-модели. Затем обновить courtyard и маркировку,
  выполнить DRC и пробную 3D-сборку. Отверстия под выбранные выводы проверить
  отдельно: шаг и контур корпуса не задают сверловку.
