# Заготовка для изготовления

Файл платы: `../Order_Combined.kicad_pcb`. Файл для передачи изготовителю: `VolumeControl_Combined_0.5mm_Gerbers.zip`.

В заготовке две электрически независимые платы: ALPS слева, ремонтная справа. Общий габарит 82,7 × 81,376108 мм, толщина обеих 0,5 мм, два слоя меди. Между ними замкнутый фрезерованный паз шириной 1 мм, длиной 53,7 мм, радиусом торцов 0,5 мм. На концах оставлены две перемычки длиной 3 мм; после изготовления их разрезать вдоль паза и зачистить до исходных контуров. Разделить платы до установки деталей. Перемычки без меди. V-cut не используется.

В архив входят F.Cu/B.Cu, маски, шелкография, Edge.Cuts (внешний контур и внутренний паз), PTH/NPTH Excellon и Gerber job. Справочная заводская медь в производство не включена. Всего 45 металлизированных отверстий, из них 5 краевых полуотверстий Ø1 мм, и 5 неметаллизированных Ø3 мм.

В заказе явно указать: FR4 0,5 мм; два слоя; медь 35 мкм; пять металлизированных полуотверстий (castellated holes); внутренний паз 1 мм; два разных рисунка плат на одной соединённой заготовке. Изготовитель должен подтвердить сочетание толщины 0,5 мм, полуотверстий и фрезы 1 мм; это не универсальный стандартный тариф.

Это текущая проверенная геометрия для предварительного согласования заказа. До запуска изготовления остаётся примерка фактических потенциометров и выводных резисторов, ранее согласованная с владельцем. Модель баланса является механическим аналогом, модель моторизованного ALPS — габаритной.

Проверка KiCad: 0 ошибок, 0 несоединённых площадок при зазоре 0,25 мм и ширине дорожки 1 мм. Предупреждения о неподключённых библиотеках и мелкой надписи сохранены в `../validation/order-combined-drc.json`; посадочные места встроены в PCB.

Общий вид установленного узла — `../VolumeControl.kicad_pcb`; его Gerber не заказывать. Для изменения разводки редактировать `../Repair_Reference.kicad_pcb` и `../ALPS_Adapter.kicad_pcb`. Затем заново сформировать заготовку через `../build_order_board.py` и выгрузить Gerber/сверловку: существующий ZIP автоматически не обновляется.
