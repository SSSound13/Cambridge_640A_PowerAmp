# Sources and licensing

SamacSys RK27112MC01P, version 1.1, released 2017-07-22, supplied by the user in LIB_RK27112MC01P.zip. Original footprint SHA-256: bd069983eb1bee3f6f9ec505c9820ecd2ad9577a47012ec3ba68862f31dd16aa.

The archive license permits unrestricted circuit board designs and does not require credit. It prohibits redistribution of models in a form usable as PCB library components outside one's own company. Accordingly, vendor-local/ is ignored by Git; the supplier component is included only as part of the actual board design, not as a redistributable library. Users needing the standalone library must obtain it separately from SamacSys.

The imported pad geometry is unchanged. Silkscreen graphics are moved to F.Fab and a separately authored simplified 3D envelope is attached. The archive states 3D=N.

J1, J2, MP1/MP2 and H1-H4 use the installed official KiCad 10 libraries. KiCad libraries use CC-BY-SA 4.0 with the KiCad libraries exception. See https://www.kicad.org/libraries/license/ . Standard 3D models are referenced from the installation and not copied here.

The ALPS envelope model is project-authored from the linked ALPS dimensional drawings and is not vendor CAD. Source PDFs are linked, not redistributed.
